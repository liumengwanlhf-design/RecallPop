## 未验证与限制

13套主机检查和有限模拟器实验不证明自然2–5分钟检查、长期待机或厂商策略稳定。真实realme Android16、重启/时区切换、厂商撤销闹钟、secure锁屏批次、最新安装器交接、全部卡型与声音仍待验收。0.6的真实设备短流程仅为历史证据。

最终组合两次现场主动读取均由Anki返回无到期卡，未进入媒体读取，因此现场索引命中率和切换耗时没有验证。没有为验收新增卡或改变到期状态。读取阶段没有新评分，现成只读证据核对复习历史和reps保持；WAL字节变化不能称为数据库全字节不变。

30秒为拒绝迟到结果的逻辑期限，真实Binder/SAF调用可能无法及时中断；实际读、取消和牌组归还结束前会继续占用读取槽。官方评分与选择接口没有跨应用原子事务，避免同时在其他应用操作同一集合。未知写入结果不自动重试。

系统退出说明可能缺失，signal9无法确定来源。AnkiDroid偶发短暂消失的提示尚未定位。AnkiWeb同步、Android lint及新机器干净构建未完整验收。

# 0.7-test 行为与验证说明

本页记录0.7引入并在0.71中保留的行为，不包含个人牌组、设备标识或调试日志。当前版本见 [README](../README.md) 和 [版本记录](../CHANGELOG.md)。

## 达标计数

默认只有用户选择“良好”或“简单”，且AnkiDroid API读回确认写入成功，才增加达标计数。所有评分仍由AnkiDroid管理，重来/困难正常写入。可改为所有评分、良好及以上或仅简单；门槛更改只影响之后的计数，不回填0.6旧记录。未答退出及不确定写入不计数，评分不重试。

90秒结束保护和每日自动150次展示上限不变。困难不计达标不会触发立即强制复习；取卡继续遵守AnkiDroid到期队列。

## 更新边界

默认说明为 `https://pop.382910.xyz/update.json`，可保存其他HTTPS地址。检查版本并查看说明后，用户点击下载；程序验证长度、SHA256、包名、版本和签名。成功后仍需另行打开系统安装器，并由Android确认覆盖安装。首次需允许本应用安装未知应用，不静默安装或热加载代码。

只接受直接HTTPS 200，不跟随重定向。离开更新页取消操作，迟到结果不能打开安装器；更新页面期间暂停自动介入。安装包只保存在应用缓存。0.6没有更新入口，首次升级需下载覆盖安装。

## 证据及限制

原开发环境已有12组门槛/评分组合及非法评分检查、两线程2000次统计模拟、门槛与跨日检查、11项更新拒绝和三个版本边界检查、离线构建通过的记录。0.7 Pages下载曾验证电脑HTTPS响应、APK长度及SHA256；这些不证明手机网络和安装流程。

真实评分后的达标计数、手机来源授权、完整应用内下载及系统覆盖安装尚未完成真机验收。0.6的短流程证据不能直接作为0.7或0.71的重新验收。
